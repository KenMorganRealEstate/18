# Luxury Real Estate Property Landing Page
Address: 18-1750 Creek Way Drive

## Deployment & Hosting Instructions

This package contains a high-performance, self-contained luxury real estate landing page with interactive 3-view virtual staging.

### 1. GitHub Pages (Free Instant Hosting)
1. Create a repository on GitHub (e.g. `https://github.com/KenMorganRealEstate/18`).
2. Upload all files and folders in this package (`index.html`, `.nojekyll`, and the `images/` folder).
3. In GitHub, go to **Settings > Pages** and select the `main` branch root.
4. Your website will be live at: `https://KenMorganRealEstate.github.io/18/`

### 2. MLS Virtual Tour Link
Copy your live URL and paste it directly into your Board / MLS listing under **"Virtual Tour URL"** or **"Branded Website URL"**.

### 3. Netlify / Vercel
Simply drag and drop this unzipped folder into Netlify Drop (https://app.netlify.com/drop) for instant CDN hosting.
